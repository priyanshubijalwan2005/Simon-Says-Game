# ⚡ Simon Says Pro

A modern version of the classic **Simon Says memory game** built with **HTML, CSS, and JavaScript**.

## ✨ Features

- 🧠 Memory-based gameplay
- 📈 Level progression
- 🏆 High score tracking
- ⏱️ Level timer
- 🎯 Easy, Medium & Hard difficulty
- ⏸️ Pause and resume
- 🔊 Sound toggle
- 🏅 Achievements
- 📱 Responsive design

## 🕹️ How to Play

1. Start the game.
2. Watch the highlighted color.
3. Remember the complete sequence.
4. Repeat the sequence correctly.
5. Try to reach the highest level!

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
